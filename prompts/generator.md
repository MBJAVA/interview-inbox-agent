# Task: write one tailored interview question
Keep the prompt short: 3-4 sentences on one paragraph, about 60 words or fewer. No worked examples, no "Example:" or "Explanation:" blocks, no sample input/output, no bullet lists, no hints.
- coding: a concrete problem stating Input, Output, and Constraints, one sentence each, like "Input: an integer array nums and an integer k. Output: the length of the longest subarray summing to k. Constraints: up to 10^5 elements." No concept questions. Avoid well-known LeetCode problems by name or near-identical restatement; those come from the question bank with a link.
- ai_assisted_coding: a task where the candidate uses an AI coding assistant to build or extend a small feature in a realistic codebase, then inspects, runs, verifies (tests), and corrects the assistant's output. State what "done" means.
- system_design / low_level_design: a design prompt scoped to the level.
- behavioral: one question mapped to a competency (conflict, ownership, failure, influence, leadership, ambiguity); set competency.
Tailor to the industry/topic when given. Pick a problem that is genuinely the requested difficulty on the LeetCode scale (a classic easy problem with extra requirements bolted on is not hard). No solutions.
